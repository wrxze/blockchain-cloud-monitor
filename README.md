# Blockchain Cloud Monitor

Учебный статический веб-проект для практической работы: демонстрация транзакций, SHA-256, связи блоков и обнаружения изменения данных.

## Структура

- `index.html` — интерфейс приложения.
- `style.css` — оформление.
- `script.js` — создание транзакций, блоков, SHA-256 и проверка целостности.
- `_headers` — заголовки безопасности для Cloudflare Pages.

## Запуск на компьютере

Самый простой вариант — открыть `index.html` в современном браузере. Для Web Crypto API надёжнее использовать локальный сервер:

1. Откройте папку проекта в VS Code.
2. Установите расширение **Live Server**.
3. Нажмите правой кнопкой по `index.html` → **Open with Live Server**.

Данные сохраняются в `localStorage` браузера. Очистка данных сайта сбросит демонстрационную цепочку.

## Проверка работы

1. При первом запуске создаются 5 демонстрационных транзакций.
2. Заполните форму и добавьте новую транзакцию. Она появится со статусом `Pending`, затем автоматически станет `Confirmed`.
3. Нажмите **Проверить цепочку** — ожидается сообщение о целостности.
4. Нажмите **Имитировать изменение данных** — приложение изменит сумму без пересчёта хеша. Проверка должна обнаружить нарушение.
5. Обновите страницу: состояние сохраняется в браузере.

## Публикация через GitHub и Cloudflare Pages

1. Создайте на GitHub новый репозиторий, например `blockchain-cloud-monitor`.
2. Загрузите в корень репозитория все четыре файла проекта (`index.html`, `style.css`, `script.js`, `_headers`) и этот README.
3. В Cloudflare откройте **Workers & Pages** → **Create application** → **Pages** → **Connect to Git**.
4. Выберите GitHub, разрешите доступ к нужному репозиторию и выберите его.
5. Для обычного HTML-проекта укажите:
   - Framework preset: **None**
   - Build command: оставить пустым
   - Build output directory: `/` (корень репозитория)
6. Нажмите **Save and Deploy**. После публикации Cloudflare выдаст адрес сайта.
7. Для проверки автоматического развёртывания измените, например, текст в `index.html`, сохраните и отправьте коммит в GitHub. Cloudflare Pages запустит новое развёртывание.

## Важное ограничение учебной модели

Это не полноценный блокчейн и не финансовая система: нет майнинга, консенсуса, распределённых узлов, цифровых подписей или серверной базы. Хеши и данные формируются в браузере; `localStorage` не синхронизируется между устройствами. Статус `Confirmed` имитируется таймером. Для реальной системы потребуются серверная архитектура, криптографическая аутентификация и распределённое хранение.
